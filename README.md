# 📊 حساب‌یار - سیستم حسابداری فروشگاه

**حساب‌یار** یک اپلیکیشن موبایلی برای مدیریت حسابداری و فروش فروشگاه‌ها است که با **Python** و **Kivy** نوشته شده.

## ✨ ویژگی‌ها

### 📦 مدیریت کالاها
- ✅ افزودن، ویرایش و حذف کالا
- ✅ جستجوی سریع کالا
- ✅ مدیریت موجودی انبار
- ✅ ثبت قیمت خرید و فروش

### 👥 مدیریت مشتریان
- ✅ ثبت مشتریان جدید
- ✅ ویرایش و حذف اطلاعات مشتری
- ✅ جستجوی مشتری
- ✅ ذخیره تاریخ تماس‌ها

### 🛒 سیستم فروش
- ✅ ثبت فاکتور فروش
- ✅ افزودن اقلام به سبد خرید
- ✅ محاسبه خودکار جمع کل
- ✅ کاهش خودکار موجودی

### 💳 مدیریت هزینه‌ها
- ✅ ثبت هزینه‌های روزانه
- ✅ جستجوی هزینه‌ها
- ✅ ویرایش و حذف هزینه

### 📈 گزارش‌ها و آمار
- ✅ نمایش کل فروش
- ✅ محاسبه کل هزینه‌ها
- ✅ محاسبه سود خالص
- ✅ داشبورد با اطلاعات لحظه‌ای

## 🛠 نیازمندی‌ها

```bash
Python 3.8+
Kivy 2.1+
KivyMD 0.104+
SQLite3
```

## 📥 نصب

1. **کلون کردن ریپوزیتوری:**
```bash
git clone https://github.com/mbehrozi1991-dot/hesabyar.git
cd hesabyar
```

2. **نصب وابستگی‌ها:**
```bash
pip install kivy kivymd
```

3. **اجرای اپلیکیشن:**
```bash
python main.py
```

## 📱 استفاده

### صفحه اصلی (داشبورد)
- نمایش موجودی انبار
- فروش امروز
- هزینه امروز
- سود ماهانه
- تعداد کالاها و مشتریان

### صفحه کالاها
- لیست کل کالاهای موجود
- جستجو برحسب نام
- افزودن کالا جدید
- ویرایش و حذف کالا

### صفحه مشتریان
- مدیریت لیست مشتریان
- افزودن مشتری جدید
- جستجوی سریع

### صفحه فروش
- افزودن کالا به سبد
- محاسبه خودکار جمع
- ثبت فاکتور

### صفحه هزینه‌ها
- ثبت هزینه جدید
- لیست هزینه‌های ثبت شده

### صفحه گزارش‌ها
- آمار کل فروش
- آمار کل هزینه‌ها
- محاسبه سود

## 🗄️ ساختار دیتابیس

اپ از **SQLite** استفاده می‌کند و جداول زیر را ایجاد می‌کند:

- **stores** - اطلاعات فروشگاه
- **products** - لیست کالاها
- **customers** - مشتریان
- **sales** - فاکتورهای فروش
- **sale_items** - اقلام هر فاکتور
- **expenses** - هزینه‌های ثبت شده

## 📂 ساختار پروژه

```
hesabyar/
├── main.py              # فایل اصلی اپلیکیشن
├── database.py          # مدیریت دیتابیس SQLite
├── hesabyar.kv          # رابط کاربری (Kivy)
├── screens/
│   ├── home.py          # صفحه داشبورد
│   ├── products.py      # صفحه کالاها
│   ├── customers.py     # صفحه مشتریان
│   ├── sales.py         # صفحه فروش
│   ├── expenses.py      # صفحه هزینه‌ها
│   └── reports.py       # صفحه گزارش‌ها
└── buildozer.spec       # تنظیمات بسته‌بندی برای اپ
```

## 🚀 بسته‌بندی برای موبایل

برای تبدیل اپ به فایل **APK** برای اندروید:

```bash
buildozer android debug
```
